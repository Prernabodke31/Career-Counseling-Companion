System Workflow — Agentic Career Counseling Companion

End-to-End Agentic Flow  |  IBM Granite · WatsonX.ai · FastAPI · React

1
POST/api/auth/register  →  JWT Token Issued
Student registers with name, email, password. Password hashed with bcrypt. JWT token returned via python-jose. Token secures all subsequent API calls.
2
DBAcademic Profile → StudentProfile + AcademicRecord (SQLite)
Student fills: GPA, field of study, grade level, skills, interests, extracurriculars, work-style preference. Subject grades stored as individual AcademicRecord rows (subject, grade, score, semester, year).
3
DB3× Psychometric Assessments → Assessment Table
Interest — 10 Qs (analytical, technical, social, creative, leadership, medical, quantitative, business, humanitarian, research)
Aptitude — 8 Qs (numerical, verbal, spatial, digital_literacy, technical_reasoning, stress_tolerance, multitasking, analytical)
Personality — 8 Qs (extroversion, conscientiousness, adaptability, empathy, risk_tolerance, specialization, achievement_drive, structure_preference)
Likert 1–5 → normalized to 0–100 per dimension → stored as JSON in Assessment table.
4
IBM AIPOST /api/career/recommend → CareerCounselingAgent
_build_student_data() aggregates all profile + academic records + latest 3 assessments from SQLite.
market_service.get_market_overview() fetches live job trends (JSearch API / fallback).
CAREER_RECOMMENDATION_PROMPT injects 14+ variables (name, GPA, grade_level, field_of_study, interests, skills, extracurriculars, work_style, location, academic_records, interest_scores, aptitude_scores, personality_scores, market_context).
Sent to IBM Granite ibm/granite-3-8b-instruct — MAX_NEW_TOKENS=1024, TEMP=0.7, TOP_P=0.95.
IBM Granite Output (ibm/granite-3-8b-instruct on WatsonX.ai)
Top 3 Career Pathways  ·  6-Step 12-Month Action Plan  ·  Skills Gap Analysis
+ 2 Alternative Pathways  ·  Motivational Summary  ·  Persisted to CareerPlan table (confidence_score = 0.85)
5
IBM AIChat Counselor
POST /api/career/chat
Last 6 exchanges from ChatSession replayed to IBM Granite → context-aware multi-turn counseling. Full history persisted in SQLite.
6
EXTMarket Intelligence
GET /api/market/overview
JSearch API (httpx async) → fallback: 10 hot roles, salary $75k–$190k, AI/ML growth 40% by 2030, top 10 companies.
7
React + Vite Frontend Dashboard (Port 3000)
8 pages: Register · Login · Dashboard · Profile · Assessment · CareerPlan · Chat · Market. Career match score charts, skills radar, market trends — all rendered with Recharts. API calls via Axios with JWT interceptors.
